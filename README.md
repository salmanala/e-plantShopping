# Paradise Nursery Shopping Application

Paradise Nursery is a React-based online houseplant shopping application.

## Features

- Paradise Nursery landing page
- Company information section
- Three houseplant categories
- At least six plants per category
- Plant images, names, and prices
- Add to Cart functionality
- Dynamic cart item count
- Redux Toolkit state management
- Increase and decrease item quantities
- Delete items from the shopping cart
- Dynamic total cost calculation
- Continue Shopping button
- Checkout button with a "Coming Soon" message
- Navigation links for Home, Plants, and Cart

## Technologies Used

- React
- Vite
- Redux Toolkit
- React Redux
- React Router DOM
- JavaScript
- CSS
